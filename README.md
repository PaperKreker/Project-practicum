# Fablehand

Карточный рогалик, в котором игрок сражается с монстрами с помощью покерных комбинаций из игральных карт, продвигается по процедурно генерируемой карте, покупает пассивные улучшения — сигилы — и побеждает боссов, проходя акт за актом.

---

## Описание проекта

**Fablehand** — это короткосессионный карточный рогалик с акцентом на быстрое тактическое мышление. Игрок получает руку из стандартной 52-карточной колоды, но с уникальными мастями (Камень, Огонь, Солнце, Луна), выбирает до 5 карт для составления покерной комбинации и атакует ею врага. Каждый враг обладает уникальным эффектом, который меняет правила боя — это требует адаптации стратегии на ходу. Между боями игрок путешествует по карте, посещает магазины и места отдыха, постепенно усиливая свой билд сигилами.

Игра состоит из **3 актов**, каждый из которых завершается схваткой с боссом.

## Механики игры

### Общая структура — что происходит за одно прохождение

Забег состоит из **3 актов**. Каждый акт — это процедурно сгенерированная карта с узлами, по которым игрок прокладывает маршрут. На карте встречаются четыре типа узлов:

- **Бой** — сражение с обычным монстром, после победы игрок получает монеты.
- **Элита** — усиленный враг, сложнее обычного, но даёт больше монет.
- **Магазин** — здесь можно потратить накопленные монеты на сигилы (пассивные улучшения).
- **Отдых** — восстанавливает 40% от недостающего здоровья.

В конце каждого акта — **схватка с боссом**. Победив всех трёх боссов, игрок выигрывает забег.

---

### Как устроен бой

Бой — это пошаговая дуэль между игроком и монстром. Вот что происходит за один **раунд**:

**1. Игрок атакует несколько раз.**
В начале раунда игроку выдаётся несколько атак (зависит от врага, обычно 2–3). Каждый раз игрок выбирает карты из руки и разыгрывает комбинацию.

**2. Игрок выбирает карты и составляет покерную комбинацию.**
В руке у игрока **8 карт** из стандартной 52-карточной колоды. Масти в игре нестандартные: Камень, Огонь, Солнце, Луна. Игрок выбирает **от 1 до 5 карт** и нажимает «Атаковать». Игра автоматически определяет лучшую покерную комбинацию из выбранных карт — чем сильнее комбо, тем больше урон. Использованные карты уходят в сброс, рука пополняется новыми из колоды.

**3. Если атаки исчерпаны — враг бьёт в ответ.**
Когда все атаки раунда потрачены, враг наносит игроку фиксированный урон и начинается следующий раунд.

**4. Сброс — способ обновить неудобные карты.**
Если текущие карты не дают хорошей комбинации, игрок может сбросить выбранные карты (без атаки) и добрать новые. За бой доступно **2 сброса** — это ограниченный ресурс.

**5. Бой заканчивается**, когда HP врага опускается до 0 (победа) или HP игрока опускается до 0 (поражение).

### Комбинации

Урон комбинации зависит от её ранга — чем она сильнее, тем выше базовый урон. Игра распознаёт 10 типов комбо:

| Комбо | Пример |
|---|---|
| Соло | Любая одиночная карта |
| Дуэт | 2 карты одного ранга |
| Квартет | Два дуэта |
| Триада | 3 карты одного ранга |
| Ряд | 5 карт подряд по рангу |
| Поток | 5 карт одного цвета |
| Крепость | Дуэт+Триада |
| Бастион | 4 карты одного ранга |
| Катаклизм | Поток одного цвета |
| Fable Hand | A-Q-K-J-10 одного цвета |

---

### Сигилы — пассивные улучшения

Сигилы — это артефакты, которые покупаются в магазине и остаются активными до конца забега. Они пассивно усиливают атаки, дают защиту или открывают новые возможности. Урон от атаки считается так: `(базовый урон комбо + бонусы сигилов) × множители сигилов`. Примеры сигилов:

- **Луна / Солнце** — каждая карта соответствующей масти в комбо наносит +10 урона
- **Изоляция** — комбо «Соло» даёт +20 урона
- **Флоу** — комбо «Поток» получает +45 урона
- **Злой умысел** — первая атака в каждом бою получает +20% к урону
- **Ярость** — когда HP падает до 40% и ниже, все атаки +20% к урону
- **Форт** — первая атака врага в бою на 35% слабее
- **Двойная связь**, **Сила**, **Обращение**, **Медиация** и другие

---

### Враги и их эффекты

Каждый враг обладает уникальным пассивным эффектом, который меняет правила боя и требует корректировки стратегии:

| Уровень | Враг | Эффект |
|---|---|---|
| Обычный | Волк | Уменьшает количество доступных сбросов |
| Обычный | Ворон | Часть карт лежит рубашкой вверх — цвет и ранг скрыты |
| Обычный | Лис | Одна случайная масть не наносит урона в этом бою |
| Элита | Альфа-волк | Каждый сброс наносит урон игроку |
| Элита | Василиск | Случайно «окаменяет» карты в руке — их нельзя сбросить или сыграть |
| Элита | Скарабей | Меньше урона при длинных комбинациях |
| Босс | Минотавр | Урон увеличивается с каждым раундом |
| Босс | Паук | Если атаковать тем же типом комбо дважды подряд — блокирует весь урон |
| Босс | Амальгам | Рандомизирует свои эффекты |

## Запуск проекта

### Предварительные требования
- Unity **2022.3 LTS** или новее
- Windows 10 / 11

### Сборка и запуск
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/PaperKreker/Project-practicum
   ```
2. Откройте папку проекта в Unity Hub и запустите через редактор **или** скачайте готовую сборку из раздела Releases
3. Запустите `Fablehand.exe`.
